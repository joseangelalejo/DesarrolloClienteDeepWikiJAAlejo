## Introducción a JavaScript

La dificultad principal de JavaScript es que te permite hacer de todo. Esto requiere tener unas bases sólidas y unos estándares y buenas prácticas bien consolidados.

JavaScript es un lenguaje interpretado que se ejecuta en el motor del navegador. JavaScript suele decirse que solo comparte con Java el nomnbre y, a diferencia de este, cuando hay un error en el código no cesa el flujo de ejecución, lo ejecuta igualmente.
Por ello es importante **formatear adecuadamente nuestro código**.

JavaScript nos permite dar **dinamismo** al HTML y CSS con el que interactúa el usuario.

Para ello el usuario interactuará con elementos como botones y campos de texto, conformando formularios de datos.
