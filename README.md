# Desarrollo Web en Entorno Cliente

Repositorio de apuntes, ejemplos, boletines y recursos de **Desarrollo Web en Entorno Cliente (DWEC)** para todo el curso de 2º DAW.

El contenido se organiza por unidades para poder añadir nuevos temas sin mezclar apuntes, ejercicios y recursos.

---

## Unidades

- [Unidad 1 - JavaScript](Unidad1/)

En este repositorio se irán incorporando las siguientes unidades a medida que avance el curso.

---

## Cómo usar este repositorio

1. Entra en la unidad que quieras estudiar.
2. Lee el `README.md` de esa unidad.
3. Consulta los apuntes y cheatsheets.
4. Practica con los ejemplos y boletines.
5. Revisa los exámenes y ejercicios de referencia.

> **Nota:** Los apuntes personales son una guía de estudio basada en el material de clase. En el examen siempre hay que respetar el enunciado, los nombres del diagrama y el HTML entregado.

---

## Material del profesor

El material original se conserva dentro de cada unidad, principalmente en:

- `Ejemplos/`
- `Enunciados/`
- `Libros y PDFs/`
- `EjemplosClase/`

Los recursos no se sustituyen por los apuntes: los apuntes ayudan a orientarse y los archivos originales son la referencia completa.
